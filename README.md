# Портфолио методиста дошкольного образования

Готовая сборка сайта **Жапашевой Айсулу Мухамедовны** — методиста
дошкольного образования, Астана.

Репозиторий содержит только результат сборки: исходный код живёт отдельно.
Правки вносятся там и выкладываются сюда командой `npm run deploy`,
поэтому файлы здесь менять вручную не нужно — следующая выкладка их перезапишет.
